## 🧭 一、控制接口剖析与避坑指南

> [!WARNING]
> **历史陷阱警示**：早期网络流传的部分示例中出现的 `/vbot/sportmode_cmd` 话题，在 **V1.6.0 固件中已被彻底废弃**。向其发包没有任何系统节点订阅，指令会被静默丢弃！
>
> 官方唯一标准实时底盘速度控制接口为：
> - **话题名称**：`/vel_cmd`
> - **消息类型**：`geometry_msgs/msg/Twist`
> - **所属中间件域**：ROS 2 Humble / Aorta Bridge (Domain ID: 178)

### 为什么必须维持 20Hz 连续发包？
机器狗底层运控节点内置了 **通信看门狗 (Hardware Watchdog)**：
* 若在 **0.5 秒 (500ms)** 内没有收到任何新的速度指令，机器狗将判定上层控制节点崩溃或网络断开，**立即进入自动安全悬停模式**并归零速度；
* 因此，单次发布一条消息机器狗只会“抽搐一下”；必须以 **10Hz ~ 20Hz** 的周期持续投递速度向量。

## 🐍 二、编写生产级 Hello World 脚本 (`hello_motion.py`)

登录机器狗终端，使用文本编辑器创建 `hello_motion.py`：

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""
VBOT EDU 极速入门：/vel_cmd 20Hz 连续速度控制示例
版权所有 (C) 2026 VBOT 开发者社区
"""

import sys
import time
import argparse
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import Twist

class VbotMotionController(Node):
    def __init__(self, target_linear_x=0.2, target_angular_z=0.0, duration=3.0):
        super().__init__('vbot_hello_motion_node')
        # 创建发布者，连接到核心话题 /vel_cmd
        self.publisher = self.create_publisher(Twist, '/vel_cmd', 10)
        
        self.target_linear_x = target_linear_x
        self.target_angular_z = target_angular_z
        self.duration = duration
        
        # 设定 20Hz 循环定时器 (0.05s)
        self.frequency = 20.0
        self.timer_period = 1.0 / self.frequency
        self.timer = self.create_timer(self.timer_period, self.timer_callback)
        
        self.start_time = time.time()
        self.is_stopping = False
        self.get_logger().info(f"🚀 控制节点已就绪：线速度={target_linear_x}m/s, 角速度={target_angular_z}rad/s, 持续={duration}s")

    def timer_callback(self):
        elapsed = time.time() - self.start_time
        msg = Twist()

        if elapsed < self.duration and not self.is_stopping:
            # 正常前进阶段
            msg.linear.x = float(self.target_linear_x)
            msg.angular.z = float(self.target_angular_z)
            self.publisher.publish(msg)
            self.get_logger().info(f"[{elapsed:.2f}s] 发布速度: vx={msg.linear.x:.2f}, wz={msg.angular.z:.2f}", throttle_duration_sec=0.5)
        else:
            # 达到预定时间，发送零速度停车并安全退出
            self.emergency_stop()
            self.get_logger().info("🏁 动作执行完毕，已平稳停车！")
            self.destroy_timer(self.timer)
            raise SystemExit

    def emergency_stop(self):
        """下发全零速度，确保硬件安全"""
        self.is_stopping = True
        stop_msg = Twist()
        stop_msg.linear.x = 0.0
        stop_msg.linear.y = 0.0
        stop_msg.linear.z = 0.0
        stop_msg.angular.x = 0.0
        stop_msg.angular.y = 0.0
        stop_msg.angular.z = 0.0
        for _ in range(5):  # 连续投递 5 次确保送达
            self.publisher.publish(stop_msg)
            time.sleep(0.02)

def main():
    parser = argparse.ArgumentParser(description="VBOT 基础运控 Hello World")
    parser.add_argument("--speed", type=float, default=0.2, help="线速度 (m/s)，建议 0.1 ~ 0.5")
    parser.add_argument("--turn", type=float, default=0.0, help="旋转角速度 (rad/s)")
    parser.add_argument("--duration", type=float, default=3.0, help="运动持续时间 (秒)")
    parser.add_argument("--confirm-motion", action="store_true", help="显式运动安全授权标志")
    args = parser.parse_args()

    if not args.confirm_motion:
        print("⚠️ [安全保护拦截] 未指定 --confirm-motion 参数！")
        print(f"👉 预览目标动作：以 {args.speed} m/s 前进，持续 {args.duration} 秒。")
        print("若确认机器狗周围无人员与障碍物，请添加 --confirm-motion 重新执行。")
        sys.exit(0)

    rclpy.init()
    controller = VbotMotionController(
        target_linear_x=args.speed,
        target_angular_z=args.turn,
        duration=args.duration
    )

    try:
        rclpy.spin(controller)
    except (KeyboardInterrupt, SystemExit):
        controller.get_logger().warn("⚠️ 接收到退出信号，紧急下发全零速度刹车！")
        controller.emergency_stop()
    finally:
        controller.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()
```

## 🏃 三、实机运行与验证

### 1. 加载 ROS 2 环境
在 SSH 终端中确保环境变量已注入（默认已在 `/etc/profile` 或用户 `.bashrc` 中配置）：
```bash
source /opt/vita/ros/humble/setup.bash
export ROS_DOMAIN_ID=178
```

### 2. 安全离线预览
先不加安全标记，测试脚本逻辑：
```bash
python3 hello_motion.py --speed 0.2 --duration 2.0
```
**终端输出**：
```text
⚠️ [安全保护拦截] 未指定 --confirm-motion 参数！
👉 预览目标动作：以 0.2 m/s 前进，持续 2.0 秒。
若确认机器狗周围无人员与障碍物，请添加 --confirm-motion 重新执行。
```

### 3. 迈出第一步
将机器狗放置在空旷地面，带上安全参数启动：
```bash
python3 hello_motion.py --speed 0.2 --duration 2.0 --confirm-motion
```
你会看到机器狗稳稳迈开四肢向前匀速行走 2 秒，随后自动刹车并停在原地。
