本模块要点

  • 直接服务与 RCP 两条控制路径必须有序切换，禁止无序并发争抢物理资源
  • 17 点骨骼输出的置信度是 Logit 不是概率，先 sigmoid 再判决
  • MCP 服务把设备能力暴露给外部 Agent，但执行仍受 RCP 与安全看门狗约束
🚨 运动安全 含 motion_control 章节：实机测试必须开阔场地、有人监护、物理急停在手边；软件急停不能替代物理急停。
