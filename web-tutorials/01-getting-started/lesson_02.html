一、硬件端口与连接拓扑

VBOT 狗身具备两个核心计算单元，接入前必须先分清你要连的是哪一块板：

  1. 计算主板（192.168.126.2）搭载 128 TOPS 算力、Ubuntu 22.04 LTS 与 ROS 2 Humble，是开发者编写算法和运控代码的宿主机——日常开发连的就是它。
  2. 主控网关板（192.168.127.10）运行实时系统（RTOS），掌管整机电源管理、低级外设、Wi-Fi 与蓝牙。

二、接入方案 A：Type-C 有线网口直连（最稳固）

有线连接具备最高优先级、最低延迟和最强抗干扰能力，是高频运动控制、大模型部署与黑客松现场调测的首选方式。

1. 物理连线

  1. 插入机器狗端使用配备的 Type-C 转千兆网口转接头，插入机器狗背部/腹部的扩展 Type-C 口（对应板载 eth2 物理网卡）。
  2. 连接电脑端另一端用网线连接至你的电脑网口。

2. 本地电脑网卡静态 IP 配置（避坑关键！）

为避免 DHCP 自动分配失败，必须将电脑连接机器狗的网卡设置为静态（Static）IP：

参数项推荐配置值深度工程解析
IP 地址 192.168.126.100 ⚠️ 严禁配置为 192.168.126.2！配成 .2 会导致电脑与机器狗 IP 严重冲突，网络死锁！
子网掩码 255.255.255.0（/24） 确保与 192.168.126.x 处于同一广播域
默认网关 留空（不填） 留空可防止此网卡接管电脑外网访问路由，避免电脑无法上网查文档
DNS 留空（不填） 局域网直连无需解析域名
powershell 
# 将 "以太网" 替换为你实际的外接网卡名称
New-NetIPAddress -InterfaceAlias "以太网" -IPAddress 192.168.126.100 -PrefixLength 24
bash 
sudo ifconfig en0 192.168.126.100 netmask 255.255.255.0 up

3. 连通性测试

在终端中执行 Ping 命令：

bash 
ping 192.168.126.2
✅ 预期输出正常返回类似 64 bytes from 192.168.126.2: icmp_seq=1 ttl=64 time=0.8 ms，说明物理链路与 IP 路由已完全畅通！

三、接入方案 B：1.6 固件板载 WiFi 直连（告别网线）

📌 版本要求在 V1.6.0 及以上版本固件中，官方正式上线了板载 Wi-Fi 直连调试能力，彻底摆脱了外接转接头与网线的物理束缚。
  1. 进入开发者 Wi-Fi 模式机器狗上电开机，等待状态指示灯进入待命呼吸状态；手机 APP 连接机器狗，在「系统设置」→「开发者选项」中开启「板载 WiFi 调试模式」，或通过长按背部调试按钮 3 秒触发。
  2. 连接 AP 热点电脑无线网卡搜索名为 VBOT-EDU-XXXX 的 Wi-Fi 热点并连接（默认初始密码详见机身铭牌或官方出厂卡片）。
  3. 确认获取到的 IP连接成功后，电脑将自动通过 DHCP 获取 192.168.127.x 网段 IP，计算板在此网段下的映射入口通常为 192.168.127.2。

四、建立 SSH 免密秒连通道

🔑 默认登录凭证用户：vbot · 初始密码：vbot。首次登录后建议立即执行 passwd 修改密码。

1. 生成并推送 ed25519 密钥对

在本地终端中生成高安全性密钥并复制到机器狗：

bash 
# 本地生成密钥（已有则跳过）
ssh-keygen -t ed25519 -C "vbot-developer"

# 将公钥推送至机器狗（需输入一次默认密码 vbot）
ssh-copy-id vbot@192.168.126.2

2. 配置 SSH 别名（~/.ssh/config）

在本地电脑的 ~/.ssh/config（Windows 位于 C:\Users\<你的用户名>\.ssh\config）追加以下配置：

ssh-config 
Host vbot
    HostName 192.168.126.2
    User vbot
    IdentityFile ~/.ssh/id_ed25519
    ServerAliveInterval 30
    ServerAliveCountMax 3

🧪 小实验：SSH 别名配置生成器

按你的实际接入方式改一改参数，一键生成可直接粘贴进 ~/.ssh/config 的配置块：

ssh-config
💡 提示WiFi 直连（方案 B）请把 HostName 改成 192.168.127.2；两台狗都常用？生成两份配置、别名分别叫 vbot-a / vbot-b 即可。

3. 一秒登录自检

现在，只需在任何终端中输入四个字符：

bash 
ssh vbot

直接免密进入设备系统！执行自检命令验证硬件与系统版本：

bash 
uname -a
# Linux vbot 5.10.x-aarch64 #1 SMP Ubuntu 22.04 LTS

五、高频排错：清除 SSH Host Key 变更冲突

如果借用了另一台同 IP 的机器狗（黑客松现场尤其常见），可能会看到：

🚨 WARNING: REMOTE HOST IDENTIFICATION HAS CHANGED!SSH 检测到同 IP 主机的指纹与本地缓存不一致，会直接拒绝连接。这不是故障，而是防中间人攻击的安全机制——换狗必现。

在本地电脑执行一行命令清除旧指纹：

bash 
ssh-keygen -R 192.168.126.2

重新执行 ssh vbot 即可顺畅连接。
