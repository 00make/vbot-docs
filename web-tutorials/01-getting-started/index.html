学习路径建议

你的目标推荐路线
第一次接触 VBOT EDULesson 01 → 02 → 03，顺序学完约 35 分钟
只想尽快让狗动起来直接跳到 Lesson 02（网络）→ Lesson 03（Hello World）
用 Cursor / Claude Code 等 AI Agent 开发把本教程页面直接喂给 Agent，配合 vbot-docs/AGENTS.md 路由规约使用

开始之前

  • 机器狗已充能，开发机准备双头 Type-C 数据线或 Type-C 转 RJ45 网线
  • 准备一块至少 2m × 2m 的平整开阔场地，运动测试时必须有人在旁监护
  • 记住具身开发第一准则：软件急停永远不能替代物理急停开关
⚠️ 接口版本警示 本教程以固件 V1.6.0 为准。网络流传的 /vbot/sportmode_cmd 话题已彻底废弃，官方现行底盘速度接口为 /vel_cmd（geometry_msgs/msg/Twist，Domain ID 178）。
